# Incident read API — Phase 1

The frontend calls FastAPI; it does not query Supabase directly. FastAPI reads the existing `public.incidents`, `public.evidence`, and `public.decisions` tables. This endpoint does not change data.

## `GET /incidents/{incident_id}`

`incident_id` is a UUID. For the demo, use `8f03fdce-cc4e-4fc1-a90b-15b2122e68b8`.

Success is HTTP `200` with an incident object. `evidence` and `decisions` are arrays; they are empty arrays when no related rows exist. An unknown UUID returns HTTP `404` with `{"detail":"Incident not found"}`. A malformed UUID returns HTTP `422`.
